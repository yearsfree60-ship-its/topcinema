📶 استهلاك الإنترنت

يحسب بايتات الصور الفعلية المجلوبة من GitHub — كل الصور جاهزة مضغوطة مسبقًا عبر GitHub Actions، فهذا الرقم يعكس التوفير الحقيقي مقارنة بحجم الصور الأصلية بالموقع المصدر. تفصيل الساعات يُحفظ لآخر 40 يومًا، وما هو أقدم يُلخَّص تلقائيًا كمجموع شهري كي يبقى تبويب «سنة» دقيقًا دون تضخّم حجم التخزين.

📅 سجل الفصول اليومي

استيراد فصول من GitHub

اكتب أرقام مفردة و/أو نطاقات مفصولة بفاصلة، بأي ترتيب. مثال: 1-20,23,34,54-60,100 يولّد الفصول 1 إلى 20، ثم 23، ثم 34، ثم 54 إلى 60، ثم 100. الفصول العشرية تُكتب بنقطة: 12.5 أو 20.1.
حلّل الرابط النموذج أعلاه أولًا، ثم اختر أي رقم بداخله هو "رقم الفصل"، واختياريًا رقمًا آخر مرتبطًا يتغيّر تلقائيًا (كنمط procomic.net).
✏️ الروابط أدناه قابلة للتعديل — عدّل أو احذف أو أضف أي رابط (مفصولة بفاصلة) قبل النسخ.
يكتشف رقم الفصل داخل الرابط اللي عطيته، ويولّد كل الأرقام بين البداية والنهاية بنفس النمط (أو حسب القائمة المخصصة أعلاه إن كُتبت)، ثم يفصل بينها بفاصلة — الصيغة المطلوبة بالضبط لحقل "chapter_urls" عند تشغيل الـ workflow يدويًا من GitHub (لأنه صندوق نص سطر واحد لا يقبل أسطرًا جديدة). الصق الناتج هناك مباشرة. لروابط بها رقم مُعرِّف إضافي يتغيّر مع كل فصل (مثل procomic.net) يكتشف التطبيق هذا النمط تلقائيًا ويتعامل معه بصمت — أو استخدم "⚙️ متقدم" لتحديد ذلك يدويًا لأي رابط آخر.
هذا هو المصدر الوحيد للقراءة بهذا التطبيق. كل الفصول المستوردة هنا مضغوطة فعليًا مسبقًا من المصدر عبر خط أنابيب GitHub Actions، وتُعرض مباشرة بدون أي وسطاء أو معالجة إضافية عند القراءة.
يقرأ نفس manifest.json فقط لعرض شجرة الاختيار — لا يُحذف شيء إلا بعد التأكيد الصريح داخل النافذة، وينفَّذ الحذف الفعلي عبر GitHub Action مخصص (delete-chapters.yml) على المستودع نفسه.
